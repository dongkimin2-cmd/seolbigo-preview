# 설비고 플랫폼 — 소비자 서비스 목업

배관·설비 DX 플랫폼 **설비고**의 소비자(B2C) 플로우 전체를 클릭 가능한 형태로 구현한 검토용 목업입니다.
실제 디자인·개발 착수 전 화면 흐름과 정보 구조를 확인하는 용도이며, 데이터는 모두 예시입니다.

## 디자인 기준

숨고(soomgo.com)의 **Prisma 디자인 시스템**을 그대로 상속했습니다.
브랜드 컬러(`#693BF2`), Pretendard 타입 스케일, 스페이싱(2·4·6·8·12·16·20·24…),
라운드(칩 6 / 카드·인풋 8 / 버튼 10·12 / 모달 16), 버튼 높이(30·38·44·52),
그림자 절제와 1px 헤어라인 처리까지 숨고 프로덕션 값을 그대로 씁니다.

여기에 설비고 도메인 전용 토큰만 추가했습니다.

| 토큰 | 용도 |
|---|---|
| `--sb-urgency-{normal,watch,caution,urgent}` | AI 진단 긴급도 4단계 |
| `--sb-role-{consumer,manager,pro,insurer}` | 4개 주체 역할 액센트 |
| `--sb-range-{track,fair,mark}` | 기준가 분포 게이지 |

## 도메인 컴포넌트 (숨고에 없던 것)

- **기준가 범위 게이지** — 적정 구간 위에 중앙값·각 견적의 위치를 표시
- **긴급도 인디케이터** — 정상 / 관찰 / 주의 / 긴급
- **Before/After 슬라이더** — 손잡이를 끌어 비교, 메타데이터 검증 배지 동반
- **승인형 추가금 아이템** — 사전 정의 항목 + 표준 단가 + 근거 사진 + 승인 버튼
- **진행 타임라인** — 접수 → 방문 → 승인 → 시공 → 완료 → 보증서
- **디지털 보증서 카드** / **플랫폼 공식 내역서** / **보험 사실자료 리포트**
- **공동구매 참여 게이지 + 단가 계단표**
- **배관 상태 스코어 링**

## 서비스 7종과 진입 경로 4가지

서비스 성격에 따라 시작하는 방법이 다릅니다.

| 진입 경로 | 서비스 | 왜 이 경로인가 |
|---|---|---|
| **사진 진단** (무료 · 20초) | 누수피해복구, 누수 탐지·공사 | 증상이 겉으로 드러나 사진으로 원인을 좁힐 수 있음 |
| **사진 + 면적** (하이브리드) | 방수·도장 | 상태는 사진, 물량은 면적. ㎡ 단가로 즉시 산출 |
| **현장 실측** (무료 · 40분) | 배관 설계·교체 | 관로 길이·매립 구간에 따라 금액이 열 배까지 차이 |
| **관로 조사** (내시경 · 1시간) | 고압세정·준설 | 관 내부 상태는 밖에서 안 보임. 오염도 수치화가 선행 |
| **즉시 견적** (확정가) | 수도배관 클리닝, 난방배관 클리닝 | 규격 상품. 평형만 고르면 가격 확정, 현장 추가금 없음 |

## 화면 (37개)

홈 · 전체 서비스 → **[사진 진단]** 업로드 · 분석중 · 결과 → 유사 사례 목록 · 상세 → 견적 비교 →
사업자 필모그래피 → 예약·결제 → 승인형 추가금 → 시공 진행 트래킹 → 디지털 보증서·공식 내역서 →
보험 Fast-Track → 우리집 배관 이력 → 공동구매
**[현장 실측]** 실측 예약 · **[관로 조사]** 조사 예약 + 오염도 리포트 미리보기 · **[즉시 견적]** 확정가 예약 ·
**[사진+면적]** 방수 물량 산출

### 사업자 센터 (7화면)
대시보드 · 요청 인박스 · 견적 작성 · 필모그래피 · 신용등급 · 자재 구매 · 정산
상단 GNB의 **[사업자 센터]** 버튼으로 진입합니다.

### 관리사무소 센터 (6화면)
단지 현황 · 디지털 이력 지도 · 오염도 리포트 · 정기 세정 계약 · 입찰 대응 · 입대의 보고자료
상단 GNB의 **[관리사무소]** 링크로 진입합니다.

### 보험사 센터 (4화면)
청구 심사 · 사실자료 상세 · 손해율 절감 대시보드 · 예방 쿠폰 캠페인
상단 GNB의 **[보험사]** 링크로 진입합니다.

세 백오피스는 같은 구조(좌측 사이드 내비 + 본문)를 쓰고 헤더 태그 색으로만 구분합니다 —
사업자 gray-800 · 관리사무소 green · 보험사 blue.

## 3분 시연 동선

1. **홈** — “가격의 근거를 먼저 보여준다”는 포지셔닝. 상단 [AI 사진 진단] 클릭
2. **진단 업로드** — 사진 + 증상 + 건물 정보. [AI 진단 시작하기]
3. **진단 결과** — 긴급도 · 신뢰도 87% · **기준가 32~58만원 / 중앙값 41만원**. 여기가 매칭 플랫폼과 갈리는 지점
4. **유사 사례** — “같은 집, 같은 증상” 판례 검색형. 사례 상세에서 Before/After 손잡이 끌기
5. **견적 비교** — 3개 견적이 기준가 분포 위 어디에 있는지. 벗어난 견적은 사유 표시
6. **승인형 추가금** — 자유 기재가 아닌 **항목 선택 + 표준 단가 + 근거 사진**. 승인 전에는 시공 중단
7. **보증서 · 내역서** — 1년 안심보증 발급
8. **보험 Fast-Track** — 같은 기록이 청구용 사실자료로. **표준 분포 대조표**가 손해사정 조사를 줄이는 핵심
9. **공동구매** — B2C와 B2B를 잇는 다리. 참여 세대 ↑ → 단가 ↓

## 네 주체가 하나의 자산에 수렴하는 구조

같은 시공 1건이 네 화면에서 각각 다른 값을 만듭니다. 시연에서 이 연결을 보여주는 것이 핵심입니다.

| 주체 | 그 시공에서 얻는 것 | 확인 화면 |
|---|---|---|
| 소비자 | 기준가 · 승인형 추가금 · 1년 보증 · 보험 서류 | 진단 결과 → 승인 → 보증서 |
| 사업자 | 검증 필모그래피 1건 · 신용등급 가점 · 광고비 0원 | 필모그래피 · 신용등급 |
| 관리소장 | 좌표에 쌓이는 이력 1건 · 입대의 설명 근거 | 이력 지도 (12층 3라인) |
| 보험사 | 표준 분포 대조 1건 · 현장조사 생략 17.4만원 절감 | 사실자료 상세 |
